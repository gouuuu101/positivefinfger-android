# PositiveFinger Android（Kotlin）

提供された iOS プロジェクトを確認し、Android 向けに Kotlin で作成したプロジェクトです。

## iOS 版との対応

元の iOS プロジェクトに実装されている機能は、アプリ起動時の「PositiveFinger」タイトル表示と、キーボード拡張でのキーボード切替ボタンです。ポイントやランク表示などはコメントのみで、まだ実装されていません。

Android 版では、ホーム画面のタイトルとキーボード切替を用意し、実際に動作を確認しやすいように、追加で基本的な英語 QWERTY キーボードと入力テスト欄を実装しています。元の iOS ソースに存在しない機能は、iOS 版と同一の動作を保証するものではありません。

## 起動方法

1. Android Studio をインストールします。
2. この ZIP を展開し、`PositiveFingerAndroid` フォルダを Android Studio で開きます。
3. Android SDK Platform 35 と必要な Gradle プラグインを Android Studio で準備し、Gradle Sync を完了します。
4. Android 端末またはエミュレーターを接続し、`app` 構成を実行します。
5. アプリ内の「キーボード設定を開く」を押し、「PositiveFinger キーボード」を有効にします。
6. アプリに戻り「キーボードを選択」で PositiveFinger を選ぶと、入力テスト欄などで利用できます。

## 実装済み

- Kotlin / Android アプリのホーム画面
- Android の入力方法（IME）として登録されるキーボード
- 英語 QWERTY の文字入力、大文字切替、削除、スペース、改行
- Android のキーボード切替要求
- 入力テスト欄

## 現時点の制限

- 日本語のかな漢字変換や予測変換はありません。日本語入力時は端末にインストール済みの日本語 IME に切り替えてください。
- `?123` キーは数字・記号配列への切替ではなく、現在はプレースホルダーです。
- APK のビルドおよび実機動作確認は、この配布物の作成環境では行っていません。
- キー入力は Android の現在フォーカスされている入力欄へ送られます。ネットワーク権限は要求していません。
